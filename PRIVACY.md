# Privacy

Fan Control for Apple Watch sends pairing, configuration, state and command requests directly to the Home Assistant addresses you configure. It has no advertising, analytics or tracking SDK. Home Assistant and your configured remote-access provider handle those requests under their own policies.

Optional push refresh uses the relay at https://coffeybean.com/FanControl/ and Apple's APNs service. When enabled in HA, your HA installation sends its installation identifier, a paired-watch identifier, the watch's APNs device token and sandbox/production environment to the relay. Refresh requests identify that watch and whether selection, configuration or selected-panel state changed. Push payloads contain only a refresh hint; the watch fetches actual data directly from HA. HA credentials, entity IDs, car names, observations and exercise audio are not sent to the relay. The relay stores scoped registrations and short-lived replay-protection metadata in private server storage; unregister removes the registration when the relay is reachable. Ordinary hosting access logs may record connection metadata. Push hints never issue vehicle commands. Background polling remains available if push is disabled or unavailable.

The watch stores its independent revocable Home Assistant integration credential and approved configuration in the device-only Keychain, accessible after the first unlock following a restart. This permits passive refresh while the watch is locked. It does not store your Home Assistant account password or Spotify credentials. Forget connection removes the local credential; revoke the watch in Home Assistant to remove server access.

Push diagnostics retain up to 120 events per credential/server scope on the watch and report them to the paired HA using encrypted authenticated requests. Events contain correlation IDs, event times, selected panel identifiers and configuration revisions, not credentials or APNs tokens. HA retains up to 120 push attempts per watch, with bounded receipt histories and separate uncorrelated watch events, available through Download diagnostics. The relay retains at most 1000 attempts per installation with correlation IDs and APNs results; these establish submission outcomes, not watch delivery. Forget connection clears local diagnostic histories. These histories can contain private entity identifiers; review before sharing.

Exercise music is copied privately from your configured Home Assistant into the watch's app storage using the paired encrypted protocol. Audio stays on your HA server and watch; it is not sent to the developer or included in public source/build artifacts. The watch remembers the preferred headset's system audio-route identifier locally. Forget connection removes locally stored exercise music and that identifier. Exercise uses local playback and does not open Spotify or send Spotify playback requests. Vehicle commands and observations go through Home Assistant; they do not independently prove physical vehicle state.

Apple may provide TestFlight crash, diagnostic and beta feedback data under Apple's TestFlight policies. Do not include credentials or private entity details in public GitHub issues. Report security concerns privately through the repository's GitHub security reporting feature when available.
